# Section model tiers

`model_tier` is section data, defaulting to `default`. It never changes the evidence or deterministic facts. OpenAI reference config maps default → `DHF_MODEL_OPENAI` (`gpt-4.1-mini`) and analytical → `DHF_MODEL_OPENAI_ANALYTICAL` (`gpt-5.4-mini`). Analytical sections: SSTR release_conclusion; sFMEA hazard/function modes; both DRR suggestion sections; L01–L03. SAD/SDD and SSTR anomaly prose stay default. Anthropic/mock use their configured analytical model or the default when none is supplied. GPT-5.5 is an explicit optional reference comparison only; no nano model is permitted.

Copilot Studio chooses a model **per Prompt tool**. Day-1 question 3.2 establishes exact tenant model options. Select the approved default/analytical model on each converted Prompt, record its real deployment/model ID and tier on the section and in cache identity, and verify JSON output/size limits. Do not promise that API model aliases are present in the tenant. If the analytical option is absent, use the approved default, record `analytical_fallback_to_default` and leave analytical quality/parity pending; manual authoring remains available after refusal.

The API reference sends temperature 0 to GPT-4.1 and omits temperature for GPT-5-family calls, setting `DHF_OPENAI_REASONING_EFFORT=low`. The configured 4,000-token reasoning allowance is added to the prompt's visible-output cap to form the inclusive max_completion_tokens ceiling (8,000 when the visible cap is 4,000); reserve **all** those output tokens at the selected model price. Actual completion usage includes reasoning; do not add reasoning twice. A limit hit becomes the existing truncated/manual placeholder. Tenant controls may differ: record supported reasoning/output controls and enforce a conservative inclusive budget before unattended calls.

Prices are versioned in [prices.yaml](../../specs/llm/prices.yaml), USD per million standard text tokens: GPT-4.1 mini 0.40/1.60, GPT-5.4 mini 0.75/4.50, optional GPT-5.5 5.00/30.00. Model-specific config keys use the sanitized model ID, e.g. `DHF_OPENAI_GPT_5_4_MINI_INPUT_PER_MILLION` and `_OUTPUT_PER_MILLION`. Legacy generic OpenAI prices apply only to GPT-4.1 mini. Unknown models require explicit prices; account service-tier/region uplifts need updated overrides. Verify prices and actual tenant billing separately before paid use. [GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini), [GPT-5.5](https://developers.openai.com/api/docs/models/gpt-5.5), [reasoning and billed output](https://developers.openai.com/api/docs/guides/reasoning).

All reference paid calls use the same persisted provider ledger. Hard caps count actual plus outstanding reservations: Anthropic $2.50, OpenAI $4.00 (owner-authorized model comparisons included), with $1.50 engineer build and $0.25 run caps. Native tenant budget telemetry/cap implementation must be verified; the API USD ledger does not automatically meter Copilot Studio credits.
