# 01 — Ingest work items and source revisions

Trigger: child flow with inputs `Organization`, `Project`, `MappingFile`, `SnapshotNumber`, `ChangedAfter` (optional ISO UTC). Output: immutable artifacts, confirmed source links, Git-code input files, ingest delta and committed snapshot ID. Connection: source-reader ADO only; Dataverse writer only for the evidence store. State: CompleteIds, NativeToCanonical, Revisions, Links; retain previous complete snapshot.

1. Load `specs/ado_mapping.yaml` from the versioned SharePoint library. Parse as the provided mapping JSON contract; validate work-item types, field names, tag prefix and typed Related pairs. This is config, not an instruction received from work-item descriptions.
2. ADO **Send an HTTP request to Azure DevOps**, POST `<project>/_apis/wit/wiql?api-version=7.1`, body `{"query":"SELECT [System.Id] FROM WorkItems WHERE [System.TeamProject] = @project"}`. POST WIQL is read-only. Query a complete set for authoritative deletions; ChangedAfter optimizes refresh only and cannot establish deletions on its own.
3. Select native IDs from `body('WIQL')?['workItems']`. Process chunks of at most 200 via POST `<project>/_apis/wit/workitemsbatch?api-version=7.1`, `{"ids": [...], "$expand":"Relations"}`. Keep every `value` item. Retry transient read failures with bounded backoff; never mark a partial snapshot complete.
4. Per item GET `<project>/_apis/wit/workitems/<id>/revisions?api-version=7.1`, paging `$skip`/`$top` until no values remain. Keep native `rev`, native ChangedDate and history. Split semicolon tags, trim each, map Requirement subtype UN/SYS/SRS/RISK-CONTROL. Canonical ID is the first `DHF:` tag suffix or `ADO-<nativeId>` when absent. Read body from System.Description, criteria from CMMI.AcceptanceCriteria, severity from the mapping values, allocation from AreaPath. Never read DHF-META to determine facts. Synthetic permission comes from the Synthetic tag; malformed or absent tags prevent an external model call.
5. Normalize `Microsoft.VSTS.TCM.Steps` as XML step action/expected pairs, preserving order and decoded text; Unit-Test tag sets test level unit, otherwise system. Requirement history stores every native revision date. Residual-Anomaly tag marks defect listing; native state is retained. Source URL is `_links.html.href`, with current revision stored separately. Reject unmapped severity rather than guessing a score.
6. Build NativeToCanonical before links. Parse relation URL native target IDs; preserve source-supplied direction. Hierarchy-Reverse is derives_from; TestedBy-Reverse is verifies. For Related, require the configured source/target type pair (risk_control→hazard mitigates, software_req→risk_control implements). PR-work-item and result-defect links are handled by their native endpoints, not inferred from prose. Origin explicit; never create a trace from textual similarity. Missing target is an ingest error.
7. GET repos and source branch items/tree for the device repo; GET blob contents at pinned commit IDs, PRs and PR work items. Route files to the code boundary in deterministic_logic.md. Do not execute or modify device code. Optional hash service receives JSON file contents, paths and pinned revisions, never credentials.
8. Call the immutable snapshot commit protocol. Output `changed` when revision or canonical hash differs; include link-only source changes, added IDs and removed IDs. Expressions: `body('Batch')?['value']`, `string(item()?['rev'])`, `uriComponent(variables('Project'))`. Normalize and encode all externally supplied path parameters. Log only IDs/counts and sanitized error categories, not tokens or source secrets.

Use the connector HTTP action because generic work-item detail actions may omit fields. A full poll also catches link-only changes. [Connector limitations](https://learn.microsoft.com/en-us/connectors/visualstudioteamservices/).
