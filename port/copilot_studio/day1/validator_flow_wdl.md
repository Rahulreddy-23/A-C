# Flow 04 validator — Power Automate WDL

Use these in **Power Automate cloud flow 04**, after Parse JSON and inside `Apply_to_each` over parsed claims. They are workflow expressions (WDL), not Power Fx. The array `EvidenceIds` is built deterministically from the bounded pack. Rename action tokens if the flow designer assigns different names; test the exact expressions in the tenant before enabling unattended output. Reject unknown citations and IDs; keep rejected claims and reasons in the audit record.

1. **Citations:** `Filter array` with **From** `@items('Apply_to_each')?['citations']` and advanced condition `@not(contains(variables('EvidenceIds'), item()))`. A subsequent Condition uses `@equals(length(body('Filter_array')), 0)`. Apply the same exact-array membership to IDs extracted from claim text; substring matching is unsafe.
2. **Kind:** Condition `@contains(createArray('sourced','inferred','suggested'), items('Apply_to_each')?['kind'])`.
3. **Confidence:** For inferred/suggested claims, require a numeric value in the Parse JSON schema, then Condition `@and(not(empty(string(items('Apply_to_each')?['confidence']))), greaterOrEquals(float(items('Apply_to_each')?['confidence']), 0), lessOrEquals(float(items('Apply_to_each')?['confidence']), 1))`. For sourced claims, null is allowed; if present, use the same range condition. Use nested Conditions so `float(null)` is never evaluated. A sourced claim with no citations is downgraded to inferred with confidence 0.5 and a recorded event.

Only the `MatchAll` ID/number extraction needs [Power Fx](validator_powerfx.md). Host it in a Dataverse low-code **instant plug-in**, invoked from flow 04 with **Perform an unbound action**, passing claim text and fact/evidence arrays; consume its typed result before saving. If only Copilot Studio topic formulas are available, flow 04 returns the typed candidate to the agent topic, which validates and invokes a separate SaveValidatedClaims flow. Flow 04 cannot invoke a topic formula itself. For an unattended generation run without either host, use the blocked `numeric_unverified` compensation in [native_validator.md](../native_validator.md).

Offline reference cases are in `tests/test_day1.py`. They do not prove these WDL expressions work in BD's tenant.
